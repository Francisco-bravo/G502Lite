# Vistas del G502

Recursos de la interfaz gráfica, editados desde las dos capturas que el usuario aportó el 17 de octubre de 2026. Se usó la herramienta integrada image_gen en modo edición. No se empleó la API/CLI externa.

- `mouse-top.png`: vista superior, 1306×1204.
- `mouse-side.png`: vista lateral, 1306×1205.

Los archivos originales del usuario no se modificaron. Se quitaron anotaciones, líneas, puntos blancos y logos; se conservó el aspecto del mouse como referencia visual. Los puntos y las etiquetas nuevas son controles WPF, no píxeles de estas imágenes.

Prompts finales resumidos: «Conservar la geometría, los controles y el acabado blanco/negro/cian del G502 de la captura. Quitar textos, líneas, círculos, botones de interfaz y logos; reconstruir las superficies bajo ellos. Render limpio centrado sobre negro puro, sin nuevas marcas». Para el lateral se hizo una segunda edición dirigida a quitar el resto del logo G de la carcasa blanca, preservando los tres botones cian y la composición.

La correspondencia física de los botones se contrastó con `C:\ProgramData\LGHUB\depots\876190\g502_hero\metadata.json`: vista superior G1/G2/G3/G7/G8/G9/G10/G11; lateral G6, G5, G4 de arriba abajo. Las coordenadas dibujadas se adaptaron a los nuevos recursos y se inspeccionaron visualmente. No se incorporó el código de la interfaz original.
